========================================================
  ИНСТРУКЦИЯ ПО СБОРКЕ И ИСПОЛЬЗОВАНИЮ
  Disc Priest (Voidweaver) Accessibility Assistant v0.2
========================================================

--------------------------------------------------------
  ТРЕБОВАНИЯ
--------------------------------------------------------

1. Python 3.9 — 3.12  (скачать с https://python.org)
   При установке обязательно поставьте галочку:
   [x] Add Python to PATH

2. Windows 10 / 11 (pydirectinput работает только
   на Windows через DirectInput API).

--------------------------------------------------------
  ШАГ 1: Установка зависимостей
--------------------------------------------------------

Откройте cmd / PowerShell в папке с проектом:

    pip install -r requirements.txt

--------------------------------------------------------
  ШАГ 2: Сборка в .exe
--------------------------------------------------------

    pyinstaller --onefile --console --name DiscPriestAssistant healer_assist.py

Результат:  dist\DiscPriestAssistant.exe

--------------------------------------------------------
  ШАГ 3: Что отдать пользователю
--------------------------------------------------------

    DiscPriestAssistant.exe    (один файл)

Файл settings.json создаётся автоматически рядом с .exe
при первом запуске. Ручное редактирование НЕ нужно —
всё настраивается через калибровку (F8).

Опытные пользователи могут править settings.json:
  - Поменять клавиши способностей (abilities.*.key)
  - Подстроить кулдауны под хасту (abilities.*.cooldown)
  - Изменить HSV-диапазон под цвет HP-баров аддона

========================================================
  КАК ПОЛЬЗОВАТЬСЯ
========================================================

1. Запустите .exe ОТ ИМЕНИ АДМИНИСТРАТОРА.

2. Откройте WoW, войдите в данж / рейд.
   Убедитесь, что Grid / VuhDo / стандартные рейд-
   фреймы видны на экране.

3. КАЛИБРОВКА (3 нажатия F8):

   F8 — начало калибровки. Далее:

   a) Наведите курсор на ЛЕВЫЙ ВЕРХНИЙ угол
      HP-бара ПЕРВОГО участника группы → F8

   b) Наведите курсор на ПРАВЫЙ НИЖНИЙ угол
      HP-бара ПЕРВОГО участника → F8

   c) Наведите курсор на ЛЕВЫЙ ВЕРХНИЙ угол
      HP-бара ПОСЛЕДНЕГО (5-го) участника → F8

   Программа автоматически вычислит позиции для
   всех 5 участников (интерполяция по сетке).

4. Нажмите F9 — помощник станет АКТИВЕН.

5. Управление во время игры:
   F9              — пауза (чат, город, AFK)
   F10             — окно отладки (маски HP-баров)
   Ctrl+Shift+Q    — выход

========================================================
  РОТАЦИЯ (что делает программа)
========================================================

Disc Priest (Voidweaver) — модель Atonement:
  1. Наложить Atonement на союзников (хил-спеллы)
  2. Бить врага → урон конвертируется в лечение
     для всех, на ком висит Atonement

Приоритет действий:

  OFF-GCD (не расходуют GCD):
    * Desperate Prayer — свои HP < 20%
    * Fade — DR когда 2+ раненых

  ЭКСТРЕННО:
    * Flash Heal — если кто-то < 20% HP

  ГРУППОВОЕ ЛЕЧЕНИЕ:
    * PW: Radiance — 3+ участников < 60% HP
      (накладывает Atonement на всех 5)
      → затем 9 сек урон-фаза (Atonement лечит)

  ТОЧЕЧНОЕ ЛЕЧЕНИЕ:
    * PW: Shield — один участник < 85%
    * Plea — если Shield на КД

  УРОН (лечит через Atonement):
    1. Mind Blast (приоритет)
    2. Penance
    3. Shadow Word: Death
    4. Smite (филлер)

Переключение цели:
  * Для хила: F1-F5 (выбрать союзника) → каст → Tab
    (вернуться на врага)
  * Для урона: просто жмём клавишу (враг в таргете)

========================================================
  ВАЖНО: ЗАПУСК ОТ АДМИНИСТРАТОРА
========================================================

Библиотеки keyboard и pydirectinput требуют прав
администратора для перехвата клавиш и эмуляции ввода.

Если горячие клавиши не работают или нажатия не
доходят до WoW → ПКМ по .exe → «Запуск от имени
администратора».

========================================================
  НАСТРОЙКА HP-БАРОВ (ЦВЕТ)
========================================================

По умолчанию программа ищет ЗЕЛЁНЫЙ цвет.
Стандартные рейд-фреймы WoW используют зелёный.

Если вы используете класс-цвета в аддонах:

  1. Запустите программу, откалибруйте, нажмите F10
  2. Посмотрите на окно отладки:
     - Если маска ПУСТАЯ → цвет не совпадает
     - Если ловит ЛИШНЕЕ → диапазон слишком широкий
  3. Откройте settings.json, измените:
     hsv_lower / hsv_upper

  Справка по цветам (OpenCV HSV: H 0-179, S/V 0-255):
    Зелёный:      [35, 50, 50]  — [85, 255, 255]
    Белый (жрец): [0, 0, 180]   — [179, 30, 255]
    Оранжевый:    [10, 80, 80]  — [20, 255, 255]
    Голубой:      [90, 80, 100] — [110, 255, 255]

========================================================
  УСТРАНЕНИЕ НЕПОЛАДОК
========================================================

Проблема: Антивирус блокирует .exe.
Решение: Ложное срабатывание (типично для PyInstaller).
         Добавьте в исключения антивируса.

Проблема: Ошибка «Failed to grab screen».
Решение: ROI вышли за границы экрана. Перекалибруйте
         (F8) или удалите settings.json.

Проблема: Помощник жмёт клавиши, но в игре ничего.
Решение: Запуск от Администратора. Также проверьте,
         что биндинги в settings.json совпадают с
         вашими клавишами в WoW.

Проблема: F8/F9/F10 конфликтуют с WoW.
Решение: Отвяжите эти клавиши в настройках WoW
         (Keybindings) или поменяйте горячие клавиши
         в коде (keyboard.add_hotkey строки в main()).
