========================================================
  ИНСТРУКЦИЯ ПО СБОРКЕ — MMORPG Healer Assistant
========================================================

Эта инструкция описывает, как собрать healer_assist.py
в один .exe файл, который можно запускать без установки
Python.

--------------------------------------------------------
  ТРЕБОВАНИЯ
--------------------------------------------------------

1. Python 3.9 — 3.12  (скачать с https://python.org)
   При установке обязательно поставьте галочку:
   [x] Add Python to PATH

2. Windows 10 / 11 (pydirectinput работает только
   на Windows через DirectInput API).

--------------------------------------------------------
  ШАГ 1: Установка зависимостей
--------------------------------------------------------

Откройте командную строку (cmd) или PowerShell
в папке с проектом и выполните:

    pip install -r requirements.txt

Это установит все нужные библиотеки, включая PyInstaller.

--------------------------------------------------------
  ШАГ 2: Сборка в .exe
--------------------------------------------------------

В той же папке выполните:

    pyinstaller --onefile --console --name HealerAssistant healer_assist.py

Объяснение флагов:
  --onefile    Упаковать всё в один .exe файл
  --console    Оставить консольное окно видимым (оно
               служит интерфейсом программы)
  --name       Имя выходного .exe файла

После сборки файл будет в папке:

    dist\HealerAssistant.exe

--------------------------------------------------------
  ШАГ 3: Распространение
--------------------------------------------------------

Всё, что нужно пользователю:

    HealerAssistant.exe    ← собранный исполняемый файл

Файл settings.json создаётся автоматически рядом с .exe
при первом запуске. Пользователю НЕ нужно создавать или
редактировать его вручную — всё настраивается через
калибровку (F8).

--------------------------------------------------------
  КАК ПОЛЬЗОВАТЬСЯ
--------------------------------------------------------

1. Запустите HealerAssistant.exe
   (от имени администратора, если клавиши не работают)

2. Откройте вашу MMORPG и зайдите в игру.

3. Нажмите F8.
   Наведите курсор на ЛЕВЫЙ ВЕРХНИЙ угол полоски
   здоровья → нажмите F8.

4. Наведите курсор на ПРАВЫЙ НИЖНИЙ угол полоски
   здоровья → нажмите F8.

5. Готово! Помощник начнёт работать.
   - F9  — пауза/возобновление
   - F10 — окно отладки (полезно для настройки HSV)
   - Ctrl+Shift+Q — выход

--------------------------------------------------------
  ВАЖНО: ЗАПУСК ОТ АДМИНИСТРАТОРА
--------------------------------------------------------

Библиотеки keyboard и pydirectinput требуют прав
администратора для перехвата глобальных клавиш и
эмуляции ввода в играх.

Если горячие клавиши не работают или нажатия
не доходят до игры — щёлкните правой кнопкой по
.exe → "Запуск от имени администратора".

--------------------------------------------------------
  УСТРАНЕНИЕ НЕПОЛАДОК
--------------------------------------------------------

Проблема: Маска пустая (чёрная) в окне отладки.
Решение: Цвет HP-бара в вашей игре отличается от
         зелёного. Откройте settings.json и измените
         hsv_lower / hsv_upper.  Подсказки по цветам
         есть прямо в файле настроек.

Проблема: Антивирус блокирует .exe.
Решение: Это ложное срабатывание — PyInstaller часто
         вызывает такие реакции. Добавьте файл в
         исключения антивируса.

Проблема: Ошибка "Failed to grab screen".
Решение: Проверьте, что координаты ROI в settings.json
         не выходят за границы экрана. Перекалибруйте
         через F8.
